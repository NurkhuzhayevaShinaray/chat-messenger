Chat-messenger app

A multi-platform chat application demonstrating advanced software design patterns and real-time voice recognition. Project was implemented using Java (OOP and Design Patterns), C#, and PostgreSQL.

Project structure:

Adapter: Integrates voice recognition using the Vosk library.
Builder: Creates customizable message objects.
Factory: Generates users, messages, and channels.
Decorator: Adds extra features to messages.
Facade: Simplifies complex subsystem interactions.
Observer: Updates notifications when new messages arrive.
Strategy: Chooses different message delivery algorithms.
Visitor: Performs operations on different message types without changing their classes.


Backend: Java, C#.

Database: PostgreSQL.

Voice Recognition: Vosk library

Design Patterns: Adapter, Builder, Factory, Decorator, Facade, Observer, Strategy, Visitor
